# SmartPOS Cloud

> Plataforma inteligente de pagamentos para o varejo moderno.

## Objetivo

Projeto desenvolvido para simular uma plataforma moderna de pagamentos inspirada em soluções utilizadas pelo mercado de varejo.

## Tecnologias

- .NET 8
- ASP.NET Core
- PostgreSQL
- Redis
- Docker
- Entity Framework Core
- Kotlin (Android)
- C++
- Azure

## Arquitetura

- Clean Architecture
- DDD
- CQRS
- SOLID
- Repository Pattern
